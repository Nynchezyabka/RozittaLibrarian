- [ ] **1.2. Подключение архива.** Автопоиск папок в `output/`, чтение

- [ ] **1.3. Чтение базы Parser (read-only).** Открытие SQLite, проверка

- [ ] **1.4. `librarian.db` и FTS-индекс.** Создание своей базы,

- [ ] **1.5. Инструмент `search()`.** Префиксные формы (`слов*`),

- [ ] **1.6. Инструмент `read_post()`.** Полный пост + комментарии +
      транскрипция, пагинация (limit/offset) для больших обсуждений.

- [ ] **1.7. Экран «Поиск».** Строка → `search()` → результаты →
      клик → просмотр поста с подсветкой найденного.
- [ ] **1.8. Остальные три инструмента.** `stats()`, `whats_new()`,
      `list_shelves()` + юнит-тесты.

ссылками. То есть ей уже можно пользоваться.
