- [x] **1.1. Каркас проекта.** Репозиторий, FastAPI + одна страница +
      WebSocket по скелету Transcriber, порт 8011, авто-открытие браузера

- [x] **1.2. Подключение архива.** Автопоиск папок в `output/`, чтение
      `archive_passport.json`, карточки архивов на экране 1.
- [x] **1.3. Чтение базы Parser (read-only).** `file:...?mode=ro` +
      `PRAGMA query_only = ON`. Поддержаны схемы v1/v2 (через
      `PRAGMA user_version`). `transcriptions` читаются опционально.
- [x] **1.4. `librarian.db` и FTS-индекс.** FTS5 над `messages.text` +
      `transcriptions.text`, токенизатор `unicode61`. Схема индекса
      версионирована (`INDEX_VERSION=2`: добавлены `is_comment`,
      `post_message_id`). Перестройка автоматически при устаревании.
- [x] **1.5. Инструмент `search()`.** Префиксные формы (`слов*`),
      фильтры (author, date_from/to, source/shelf), ≤ 20 результатов,
      сниппет ≤ 300 символов. В ответе — `is_comment` и
      `post_message_id` для метки «↳ в комментарии». 22 юнит-теста.
- [x] **1.6. Инструменты `read_post()` и `get_message()`.** Пагинация
      комментариев (`limit`/`offset`). `get_message` дополнительно
      возвращает соседей (prev/next) и ссылку `t.me`. UI-4 использует
      именно его.
- [x] **1.7. Экран «Поиск» (UI-3).** Строка → `search()` → результаты →
      клик → ридер (UI-4) с подсветкой найденного. Расширенный фильтр
      (автор, дата, тип источника) сворачивается в «Точный поиск».
- [x] **1.8. Остальные три инструмента.** `stats()` (overview + authors),
      `whats_new()` (с `since`), `list_shelves()` + юнит-тесты.

## Решения, принятые по ходу

_(если по ходу работы пришлось отступить от спецификации — записать
здесь дату, что изменили и почему, и поправить спецификацию)_

- **2026-07-28 — динамические чипы.** Чипы убраны из
  `archive_passport.json` (парсер их не производит и не будет).
  Чипы вычисляются библиотекарем через `LibrarianDB.top_terms()` из
  FTS5-словаря (`fts5vocab`). Достаточно простых средних слов длиной
  ≥ 6, без интерактивности. См. `librarian_рабочий_план.md` §5.
- **2026-07-28 — `get_message` вместо `read_post` в UI-4.** `read_post`
  оставлен для совместимости, но UI использует новый `get_message`:
  одним запросом возвращает пост + транскрипцию + комментарии + соседей
  + ссылку t.me. Меньше round-trips, проще логика на клиенте.
- **2026-07-28 — `INDEX_VERSION=2`.** В `fts_doc` добавлены `is_comment`
  и `post_message_id`, чтобы в результатах поиска маркировать
  комментарии меткой «↳ в комментарии». Старые `librarian.db`
  автоматически перестраиваются при открытии архива.
- **2026-07-28 — авто-открытие браузера.** После старта uvicorn
  демон-поток ждёт 1.5 c и зовёт `webbrowser.open(url)`. Флаг
  `--no-browser` отключает для headless-окружений.
